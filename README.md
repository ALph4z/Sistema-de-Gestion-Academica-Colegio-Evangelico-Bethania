# EduBethania

Es un sistema web creado para modernizar los procesos administrativos del Colegio Evangélico Bethania. La plataforma automatiza el registro de nuevos ingresos, el control de cupos, la validación de pagos y el seguimiento del expediente académico en una sola interfaz segura y ágil.

Proyecto de monográfico para la Licenciatura en Informática — Universidad Autónoma de Santo Domingo (UASD).
