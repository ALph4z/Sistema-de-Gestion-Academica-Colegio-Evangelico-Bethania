# EduBethania

Modernización, control y eficiencia en la gestión académica escolar.

EduBethania es una solución web integral concebida para transformar y digitalizar la administración del Colegio Evangélico Bethania. El sistema centraliza y automatiza los flujos de trabajo clave desde el primer contacto de admisión hasta el seguimiento académico final en una plataforma segura, intuitiva y accesible.

✨ ¿Qué resuelve EduBethania?
Matriculación & Reinscripción Digital: Automatiza el registro de nuevos ingresos y reinscripciones, eliminando la carga del papeleo manual y la duplicidad de expedientes.

Gestión Inteligente de Cupos: Control en tiempo real de la disponibilidad por curso, nivel y tanda (Matutina/Vespertina).

Control de Pagos y Facturación: Validación instantánea de comprobantes, cobros parciales/completos y seguimiento transparente del estado financiero de cada matrícula.

Expediente Académico Unificado: Historial completo del estudiante, tutores, calificaciones y entrega de documentos en un solo lugar.

🛠️ Stack Tecnológico
Frontend: HTML5, CSS3, JavaScript, Figma (UI/UX Design)

Backend: Python (FastAPI)

Base de Datos: SQLite (Relacional con claves foráneas e integridad referencial)

Arquitectura: RESTful API & Control de acceso basado en roles (RBAC)
